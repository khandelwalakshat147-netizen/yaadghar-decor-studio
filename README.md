# Yaad Ghar Magnets

Create a professional e-commerce website named 'Yaad Ghar Fridge Magnet'. Language: Hindi + English. Purpose: sell customized fridge magnets and wall decoration gifts for birthdays, couples, memories, and special occasions. Home page with hero banner, product catalog, pricing section, photo gallery, customer testimonials, WhatsApp order button, contact form, and order inquiry form. Products: 2x2 inch Round Magnet - ₹59, 2x3 inch Round Magnet - ₹62, 3x3 inch Square Magnet - ₹79-99, 3x4 inch Rectangular Magnet - custom pricing display, 4x4 inch Magnet - ₹149-199, 4x6 inch Magnet - custom pricing display. Include categories: Birthday Gifts, Couple Gifts, Wall Decoration Gifts, Custom Photo Magnets, Memory Gifts. Modern red, gold, and white color theme. Mobile-friendly design, social media links, FAQ section, and attractive product cards with image placeholders. Add WhatsApp ordering CTA throughout the site.
